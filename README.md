# Salesforce Website Clone

A front-end clone of the Salesforce homepage, developed using HTML and CSS. The project recreates key sections of the original website, focusing on layout, visual design, styling, and CSS animations.

**This project was developed independently without using AI tools to generate the code.**

## Features

* **Navigation Bar:** Salesforce branding, navigation links, search bar, and contact options.
* **Hero Section:** Headline, descriptive content, and call-to-action buttons.
* **Agentforce Section:** Search interface with suggested queries.
* **Product Showcase:** Cards highlighting Slack, Agentforce, Customer 360, and Data 360.
* **Customer Success Stories:** Horizontally scrolling cards featuring customer information and company logos.
* **Interactive Styling:** CSS hover effects for buttons, navigation elements, and product cards.
* **CSS Animation:** Continuously scrolling customer cards using `@keyframes`.

## Technologies Used

* HTML5
* CSS3
* Remix Icon

## Getting Started

1. Clone the repository:

   ```bash
   git clone <your-repository-url>
   ```

2. Open the project directory.

3. Launch `index.html` in your web browser.

Alternatively, use the Live Server extension in Visual Studio Code.
